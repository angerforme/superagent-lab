# 玩法与数值

> 本文是手写规则说明，与 `canon/*.json` 中的数据共同构成游戏规则。
> 数值若要调整，改 `canon` 与 `server/mechanics.js`，并跑 `npm test`。

## 一、时间

- 一回合 = 一个时节（约九十日），春 → 夏 → 秋 → 冬。
- 开局：承平二十三年春；终局：承平二十八年冬。
- 全局 24 回合。结束方式只有三种：身死、终局抉择、走完年表。
- 人物年龄每过四个时节 +1；开局 16 岁。

## 二、属性与派生

| 属性 | 作用 |
| --- | --- |
| 根骨 | 气血上限、内力起点、练气效率 |
| 悟性 | 练气效率、招式熟练度增长、终局「执棋」选项门槛 |
| 福缘 | 遭遇与探秘的运气 |
| 心性 | 突破成功率、抗心魔、终局「开门」门槛 |
| 魅力 | 结交人物时的交情增益 |

派生：

```
攻势 = 8 + 境界×12 + Σ(武学攻势 × 熟练度/100) + 神兵加成 + 天赋
守势 = 6 + 境界×9  + Σ(武学守势 × 熟练度/100) + 神兵加成
身法 = 5 + 境界×5  + Σ(武学身法 × 熟练度/100)
战力 = 攻势 + 守势×0.55 + 身法×0.7      （受重伤时攻势、守势 ×0.82）
气血上限 = 基础 + Σ(武学气血上限 × 熟练度/100) + 境界×25 + 神兵
```

## 三、境界

| 境界 | 需要内力 | 说明 |
| --- | --- | --- |
| 凡体 | 0 | 初入江湖 |
| 三流 | 50 | 能对付寻常山贼 |
| 二流 | 130 | 镖师、捕头水准 |
| 一流 | 260 | 各派真传弟子 |
| 超一流 | 430 | 长老级 |
| 宗师 | 650 | 一派掌门 |
| 大宗师 | 950 | 天下前十 |
| 天人 | 1350 | 传说 |

突破必须在「闭关突破」行动中进行，成功率：

```
0.42 + 心性/320 + (当前内力 - 门槛)/1400，夹在 0.20 ~ 0.92
```

失败会受伤（气血 -16%），但不会掉境界。

## 四、行动

| 行动 | 主要收益 | 代价 / 风险 |
| --- | --- | --- |
| 打坐练气 | 内力 +10~（受悟性、根骨、内功武学影响） | 5%~9% 走火，损失气血 |
| 演练武学 | 指定武学熟练度 +6~13，少量内力 | 无 |
| 行走江湖 | 换地图、声望 +1~3、可能遇见当地人物 | 盘缠，少量伤病 |
| 拜访人物 | 交情 +4~10；交情 ≥60 可能学到对方非天级武学 | 可能扑空 |
| 探秘寻幽 | 银两、主线线索、龙泉可遇「问天」 | 伤病、埋伏 |
| 出手比试 | 声望、银两、对方交情变化 | 败则重伤 |
| 疗伤静养 | 气血恢复 | 药钱 |
| 谋生糊口 | 银两 +18~55 | 无 |
| 追查线索 | 主线线索、声望、因果 +1 | 无 |
| 闭关突破 | 境界提升 | 失败受伤 |
| 拜师入门 | 获得门派身份与一门入门武学 | 需要所在地、交情或声望 |
| 问心静坐 | 心性 +1，气血小回 | 无 |

## 五、战斗

`战力 + 随机(-12,12)` 对比 `对手战力 + 随机(-12,12)`，高者胜。
NPC 战力 = `24 + canon.power × 1.1`；杂兵按类型固定（山贼 42、刀客 54、缇骑 75、血卫 82、游侠 62）。
败方受伤，玩家败北受伤量随对手战力上升；不会一次性打死玩家，但气血归零即身死。

## 六、声望、因果与交情

- **声望**：0 起，公开行动的累积。高声望解锁「拜师」与「天下第一」结局，也会招来更强的对手。
- **因果**：-100 ~ +100。行侠、查案、守门为正；血月、掠夺、杀戮为负。终局判定「侠之大者」「魔道至尊」。
- **交情**：-100 ~ +100。≥80 生死之交，≥50 知己，≥20 熟识；≤-80 死敌。终局「归隐」要求有人与你交情 ≥70。

## 七、终局

第 24 个时节（承平二十八年冬）呈现四个抉择，可用选项受这一生积累限制：

| 抉择 | 门槛 | 指向 |
| --- | --- | --- |
| 以问天斩断九鼎之门 | 持有问天 | 问天 |
| 以身守门 | 无 | 侠之大者（因果 ≥ -20） |
| 推开九鼎之门 | 心性 ≥40 | 天倾；若入魔道且境界足够则魔道至尊 |
| 拾起黑子坐上棋盘 | 悟性 ≥55 | 执棋人 |

结局判定见 [结局录](06-结局录.md)，按优先级取第一个满足条件的结局；身死优先于一切。

## 八、暗线与解锁

人物的 `secret` 默认不下发给玩家、不进入提示词。主线事件可以设置 `reveal`（例如第 18 个事件揭露清虚真人），
触发后对应 `revealFlag` 写入状态，守卫才允许叙述者提到「执棋人」「沈砚」等词。

## 九、可扩展点

- 新增门派：`canon/sects.json` 加条目，补山门、掌门、绝学引用，`npm test` 会检查引用完整性。
- 新增武学：`canon/arts.json`；若给 NPC 学，同步 `characters.json`。
- 新增主线事件：`storyline.json` 的某一幕里加 beat，`turn` 会由年份与季节自动算出；同一时节不能有两个事件。
- 新增行动：`server/mechanics.js` 的 `HANDLERS` + `director.js` 的候选池 + 前端 `MECH_LABEL`。
